This dataset was selected as part of a project originally developed in a MCDC practicum course or a Data -science Application for Undergraduates (DAU) summer project in response to a request from and in collaboration with a non-profit community organization, represented by a community partner.

Students worked in teams to respond to the community partner's Request for Data Science Services through MCDC. Results from this and other MCDC student–community partnership projects are summarized on the [MCDC Past Projects website](https://sites.northwestern.edu/mcdc/student-internships-and-projects/). The MCDC program was funded by the U.S. National Science Foundation.
